# Cabinet Landing v1 Archive

This folder preserves the previous Cabinet of Curiosities homepage before the
archipelago-map rebuild.

- `cabinet-index.md.bak` — the old `docs/index.md`, a plain MkDocs Material
  content page listing links out to jesalmehta.com and other worlds.

Archived during the `cabinet-map-v2` branch work (see `README.md` /
`LANDING-PAGE-NOTES.md` at the repo root for the current architecture). The
pre-rebuild state of `main` is also tagged `cabinet-v1-before-map` in git, so
the full old site can be rebuilt with `git checkout cabinet-v1-before-map` if
ever needed.

Kept outside `docs/` on purpose (matching Bookshelf's
`archived-landing-pages/*.bak` convention) so MkDocs does not build this as a
live, unlinked page.
