# dev-archive/

Permanent, committed screenshots documenting how features actually
shipped -- visual history alongside the written changelog
(`Landing-page-notes.2.0.md`) and ToDo (`landing-v3/three-world-launch-
phases-ToDo.md`). Not gitignored, unlike `review/` -- these are meant to
stay in git history.

Added from two directions: proactively while working on a feature (a
before/after pair, or a key state worth remembering), and by hand-picking
images out of `review/` worth keeping once a round of review is settled.

No fixed structure yet -- flat files with descriptive names for now,
dated if it helps (`2026-08-24-fab-section-treemap-reflow.png` etc.);
reorganize into subfolders later if it grows unwieldy.
