# review/

Working screenshots for in-progress changes -- before/after pairs shown
for approval before a change is committed. Gitignored, not part of
history: this folder is expected to be overwritten/cleared freely
between rounds of review.

If a review image is worth keeping permanently (documents how a feature
actually shipped, not just a rejected draft), it belongs in
`landing-v3/dev-screenshots/` instead, not here -- that's the existing,
git-tracked, established location (56+ screenshots already there,
`vX.Y.Z-description.png` naming), not a new folder. (An earlier pass,
2026-08-24, briefly created a redundant `dev-archive/` at the repo root
without checking for this first -- removed the same day.)
