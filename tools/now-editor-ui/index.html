Now editor

Edits content/now.tsv and now-data.js directly on disk. Local only -- nothing here is deployed. Rebuild writes docs/now.md; if you have mkdocs serve running elsewhere, it live-reloads from there.

Add a new section

Adding a section here only edits now-data.js's config -- it won't show on the page until it has at least one entry in now.tsv.
